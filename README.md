# Application d'emissions de streaming

Devoir Developpement Mobile - Formation Dclic - Atelier "Application du modele MVC"

Ce repo contient les deux versions demandees dans l'activite :

- [`version_classique/`](version_classique) : version "classique" de l'application (tout dans `main.dart`)
- `version_mvc/` : version respectant l'architecture MVC (Modele - Vue - Controleur) - 

## Version classique

Application Flutter qui affiche une grille reactive d'emissions de streaming. Un clic sur une
emission ouvre une page de detail avec une transition Hero et une liste de diffusions.

Pour la lancer :

```bash
cd version_classique
flutter pub get
flutter run
```
